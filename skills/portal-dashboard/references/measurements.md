## OCR 观测到的布局要点

- **大字数字统计**：顶部一排大字号 KPI 数字，是整页最醒目的元素 → 落地为 hero 行（v1 为 5 格统计行，v2 改为 2fr 1fr 1fr 的 hero-mini + 两张 metric 卡，32px/29px 大数字、tabular-nums、负字距）
- **等宽 IP**：IP / 端口等地址类信息用等宽字体 → 落地为等宽字体栈（命令芯片、文件类型、端口号）
- **服务表**：服务名 + 端口 + 状态指示 → 落地为服务胶囊条（7px 状态点，在线绿点亮 + 浅绿底）
- **策略组 tile**：圆角卡片列表、选中态高亮 → 落地为文档/工具卡片网格与 chip 选中态（蓝底白字）
- **右上角勾选控件**：开关/勾选类控件位于右上区域 → 落地为 header 右上角三态分段开关 + 工具栏右侧「只看当前」开关
- 其他：胶囊形控件、大圆角卡片、暖灰底低对比配色

## 落地令牌与参考图的差异

1. **无侧栏**：参考图有左侧导航栏（采样 `#e9e7e9`）。落地风格明确放弃侧栏，改为单列自上而下（header → hero 行 → services → toolbar → 区域 → 工具 → 页脚），并立为硬规则「不用侧边栏」。
2. **文档优先**：参考图是代理面板（仪表盘优先）。落地对象是知识库门户：文档区域是页面主体，参考图的「服务表 / 策略组 tile」降级为胶囊条与卡片网格，工具区永远殿后。
3. **绿色状态色降级**：采样的 `#a1f7a1` 亮度偏高，不适合做正文级主绿；主绿改用 iOS 系统绿 `#34c759`（dark `#30d158`），`#a1f7a1` 保留为 light `--green-soft`（徽章底色）。
4. **补充的复合色**（非采样，实现需要而补）：状态徽章底/字（当前 `#e7f9ec`/`#1a8f3a`，dark `#123522`/`--green`；候选 `#fff4e0`/`#b26a00`，dark `#3a2a10`/`--amber`；索引 `--blue-soft`/`--blue`）、运行中 pill（`#dcfce7`/`#166534`/`#86efac`，dark `#14351f`/`#4ade80`/`#1f6b3a`）、服务在线浅绿底 `#f2fbf5`（dark `#12251a`）、开关关态底 `#d8d5da`（dark `#3a3d44`）、服务点离线灰 `#c9c7cc`（dark `#4a4d55`）、收藏星 `#f5a623`、toast 黑白反转。完整清单见 SKILL.md「组件规格」。

## 演进记录（v1 → v2，同日）

v2 以 127.0.0.1:8791 现行门户为准，相比首版技能的变化：

| 项 | v1 | v2 |
| --- | --- | --- |
| 表面色 | `--bg:#f2f0f3 --card:#fcf9fa --line:#e8e6e8` | `--bg:#f9f7fa --card:#ffffff --line:#e4e1e6`（更亮、卡底纯白） |
| 基础阴影 | `0 1px 2px rgba(20,20,30,.035)` | `0 1px 3px rgba(20,20,30,.05)` |
| dark 卡/线 | `#17181c` / `#2a2c31` | `#1a1b20` / `#2c2e35` |
| 统计区 | 5 格 stat tile 行 | hero 行（2fr 1fr 1fr）：hero-mini（pill+32px 数字+meta+blob+⟳刷新）+ 两张 metric 卡（29px 数字 + spark 面积图） |
| 模式控件 | 44px 圆形 emoji 按钮（🌓→☀️→🌙 循环） | 三段分段开关（32×32 SVG 图标，选中蓝底白字），逻辑不变（`hub-theme-mode`、auto 不写属性） |
| 卡片 | 带 1px `--line` 边框、hover 边框变蓝 | 无边框纯 `--shadow`，hover 浮影加深；doc 卡加大（min-height 150、18px padding、18px 圆角、标题 15px） |
| 索引卡 | 虚线卡（dashed + 透明底） | 蓝色渐变卡（`linear-gradient(160deg, var(--card) 30%, var(--blue-soft) 130%)`）+ `badge.blue`「索引」 |
| 导航 | 全部 `target="_blank"` 新标签 | 同页导航（doc 卡、区域索引、服务、工具打开均走 `location.href`） |
| 新增 | — | 卡片 hover 悬浮操作层（☆收藏/🗑删除）、工具栏 ⭐/🗑 viewbtn、收藏夹/垃圾箱/确认删除弹窗体系、`api()` 离线安全封装（file:// 只读 + toast）、四接口后端约定（favs/trash/restore/purge）、搜索 focus 蓝环、服务在线浅绿底 |

## 复测方法

1. 向用户索取原图；
2. 用取色器对同一位置取样，与「采样色值」表对照；
3. 确认差异后更新本文件，并同步修改 SKILL.md 的设计令牌（如有变化）。
