## OCR 观测到的布局要点

- **大字数字统计**：顶部一排大字号 KPI 数字，是整页最醒目的元素 → 落地为 5 格统计行（24px/700、tabular-nums、负字距）
- **等宽 IP**：IP / 端口等地址类信息用等宽字体 → 落地为等宽字体栈（命令芯片、文件类型、端口号）
- **服务表**：服务名 + 端口 + 状态指示 → 落地为服务胶囊条（7px 状态点，在线绿点亮）
- **策略组 tile**：圆角卡片列表、选中态高亮 → 落地为文档/工具卡片网格与 chip 选中态（蓝底白字）
- **右上角勾选控件**：开关/勾选类控件位于右上区域 → 落地为 header 右上角三态模式按钮 + 工具栏右侧「只看当前」开关
- 其他：胶囊形控件、大圆角卡片、暖灰底低对比配色

## 落地令牌与参考图的差异

1. **无侧栏**：参考图有左侧导航栏（采样 `#e9e7e9`）。落地风格明确放弃侧栏，改为单列自上而下（header → stats → services → toolbar → 区域 → 工具 → 页脚），并立为硬规则「不用侧边栏」。
2. **文档优先**：参考图是代理面板（仪表盘优先）。落地对象是知识库门户：文档区域是页面主体，参考图的「服务表 / 策略组 tile」降级为胶囊条与卡片网格，工具区永远殿后。
3. **绿色状态色降级**：采样的 `#a1f7a1` 亮度偏高，不适合做正文级主绿；主绿改用 iOS 系统绿 `#34c759`（dark `#30d158`），`#a1f7a1` 保留为 light `--green-soft`（徽章底色）。
4. **补充的复合色**（非采样，实现需要而补）：状态徽章底/字（当前 `#e7f9ec`/`#1a8f3a`，dark `#123522`/`--green`；候选 `#fff4e0`/`#b26a00`，dark `#3a2a10`/`--amber`）、开关关态底 `#d8d5da`（dark `#3a3d44`）、服务点离线灰 `#c9c7cc`（dark `#4a4d55`）、toast 黑白反转。完整清单见 SKILL.md「组件规格」。

## 复测方法

1. 向用户索取原图；
2. 用取色器对同一位置取样，与「采样色值」表对照；
3. 确认差异后更新本文件，并同步修改 SKILL.md 的设计令牌（如有变化）。
